# Bắp và 12 Con Giáp — Bảng âm thanh con vật

A kid-friendly sound board for the 12 zodiac animals (Vietnamese).
Tap an animal card to hear its real sound. No build step, no backend,
no external dependencies — just open `index.html` in a browser.

## Run it

- **Locally:** open `index.html` in any browser.
- **Online:** deploy as a static site on Vercel (import this repo, no build
  settings needed) or GitHub Pages.

## What is it?

A companion web page for the kids' animated film
**“Bắp và 12 Con Giáp”** (Bắp and the 12 Zodiac Animals) from the
YouTube channel [VH Phước](https://www.youtube.com/@vhphuocmedia).
Each of the 12 cards plays the same real animal sound used in the film.

| # | Zodiac | Animal | Sound | File |
|---|--------|--------|-------|------|
| 1 | Tý | Chuột (Rat) | Chít chít! | sounds/chuot.mp3 |
| 2 | Sửu | Trâu (Buffalo) | Mò ò! | sounds/trau.mp3 |
| 3 | Dần | Hổ (Tiger) | Grừ grừ! | sounds/ho.mp3 |
| 4 | Mão | Mèo (Cat) | Meo meo! | sounds/meo.mp3 |
| 5 | Thìn | Rồng (Dragon) | Gào! | sounds/rong.mp3 |
| 6 | Tỵ | Rắn (Snake) | Xì xì! | sounds/ran.mp3 |
| 7 | Ngọ | Ngựa (Horse) | Hí hí! | sounds/ngua.mp3 |
| 8 | Mùi | Dê (Goat) | Be be! | sounds/de.mp3 |
| 9 | Thân | Khỉ (Monkey) | Khẹc khẹc! | sounds/khi.mp3 |
| 10 | Dậu | Gà (Rooster) | Ò ó o! | sounds/ga.mp3 |
| 11 | Tuất | Chó (Dog) | Gâu gâu! | sounds/cho.mp3 |
| 12 | Hợi | Lợn (Pig) | Ụt ịt! | sounds/lon.mp3 |

Note: in the Vietnamese zodiac, Mão is the Cat (not the Rabbit). The dragon
has no real sound, so a lion's roar is used for it, as in the film.

## Tiếng Việt

Bảng âm thanh 12 con giáp cho bé — chạm vào từng con vật để nghe tiếng kêu
thật, giống như trong phim hoạt hình “Bắp và 12 Con Giáp” trên kênh YouTube
VH Phước. Mở file `index.html` là chơi được, không cần cài đặt gì thêm.
Bảng ghi công tiếng kêu ở trên ghi rõ nguồn và giấy phép của từng file âm thanh.
